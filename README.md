# weather-app
🌤️ **Weather App UI Design**

✨ **Project Overview**

This is a Weather App UI Design created using Figma. The application provides users with accurate and easy-to-understand weather information, including current temperature, weather conditions, humidity, wind speed, and weather forecasts.

🎯 **Objective**

The main objective of this project is to design a simple, clean, and user-friendly weather application that helps users quickly check current weather conditions and upcoming forecasts.
